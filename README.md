# 🏢 NammaSpace — Hostel Room 1435 (3D Interactive Walkthrough)
**Built for IIT Bombay Techfest** | **[▶️ Launch Live 3D Demo](https://guptaniruddh.github.io/NammaSpace/)**

An interactive, zero-asset first-person 3D simulation of VIT Chennai Hostel Room 1435, the 14th-floor corridor, and coastal balcony view built from scratch using **Three.js**, **HTML5 Canvas**, and the **Web Audio API**.

### ✨ Key Technical Features
* **100% Procedural Graphics:** Custom-generated canvas textures for floor tiles, wood grain, fabrics, and a real-time animated coastal skybox (Day, Golden Sunset, Starry Night, and Monsoon Rain with lightning).
* **20 Interactive Props & Mini-Games:** Raycasted object interactions including a live-editable 3D Laptop Notepad, planar reflector wall mirror with avatar flex poses, crumpled paper-toss physics mini-game, electric kettle with particle steam, and a 5-speed ceiling fan.
* **NPC Dialogue & Autonomous Patrols:** Interactive hostel mates (*Aniruddh, Rajat, and Chirayu*) with branching dialogue, handshakes, and day/night sleep cycles.
* **Procedural WebAudio & Web Speech API:** Synthesized spatial audio (fan hum, rain, thunder, footsteps, lo-fi chord generator) and a 3-minute, 20-stage narrated auto-tour.
